Online Ready

O DevFlow v1.1.0 foi preparado para hospedagem rapida na Vercel com suporte completo para multiplas maquinas e celulares:

Como publicar na Vercel:
  1. Suba o projeto para seu repositorio no GitHub.
  2. Na Vercel, clique em Add New Project e selecione o repositorio.
  3. Clique em Deploy (o arquivo vercel.json ja esta pronto).
  4. Compartilhe o link gerado (ex: https://viemar-devflow.vercel.app) com todos da Usinagem!
