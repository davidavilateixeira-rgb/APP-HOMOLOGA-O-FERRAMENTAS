Publicacao Web (Google Firebase)

Online

Para disponibilizar o link online para a equipe acessar do computador ou celular:

  1. Acesse o Firebase Console (firebase.google.com).
  2. Crie o projeto "viemar-testes-ferramentas".
  3. Cole as credenciais no arquivo firebase-config.js.
  4. Execute firebase deploy para gerar o link web oficial.
Modo Local 100% Funcional: O aplicativo funciona offline no seu computador, salvando todos os dados no cache local e emitindo PDFs oficiais da Viemar.
